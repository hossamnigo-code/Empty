# Crystal Front

A small real-time strategy game that runs in any modern browser — desktop or phone. No install, no build step, no dependencies: just open `index.html`.

## How to play

Mine crystals with workers, build up your base, train an army, and destroy every enemy building. The red commander (AI) expands, builds defenses and attacks in growing waves. Pick Easy, Normal or Hard.

**Units:** Worker (mines and builds), Trooper (melee), Ranger (ranged), Tank (long range, splash damage)
**Buildings:** Command Hub, Supply Depot, Barracks, Factory, Guard Tower

### Touch
- Tap a unit, then tap the map to move / attack / mine
- Double-tap a unit to select all of that type on screen
- Drag to scroll, pinch to zoom, tap the minimap to jump
- **Box** button then drag to box-select · **Army** selects all combat units · **Idle** finds idle workers

### Mouse & keyboard
- Left-click / drag to select, right-click to command or set rally points
- `A` + click: attack-move · `S`: stop · `Q W E R T`: panel buttons
- `Ctrl+1-9` set control group, `1-9` recall · arrows / screen edges scroll · wheel zoom · `Space`: base · `Esc`: pause

Features fog of war, a minimap, production queues, rally points, supply limits and an AI opponent.
